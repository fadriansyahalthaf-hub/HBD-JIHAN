VERSI 2 - WEBSITE HADIAH BIRTHDAY

Buka folder ini di VS Code.
File utama:
- index.html = tahapan dan tulisan
- style.css = tampilan
- script.js = game, loading, perpindahan halaman, confetti

Jalankan:
1. Install extension "Live Server" di VS Code.
2. Klik kanan index.html.
3. Pilih "Open with Live Server".

Untuk mengganti pesan, edit teks pada p5 dan p6 di index.html.
Untuk mengganti target game, ubah score>=100 di script.js.
